# Ceklis Rekaman Audio HarakaPlay

Format: **mp3**, mono, durasi pendek (±1 detik untuk suku kata, ±2 detik untuk kata).
Simpan di folder yang ditunjuk, lalu jalankan `node scripts/scan-audio.js` agar game mengenali file baru.
File yang belum ada tidak apa-apa: game berjalan tanpa suara itu dan console tetap bersih.
